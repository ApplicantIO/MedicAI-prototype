# Medic AI — interaktiv prototip

Frontend-only demo (backend yoʻq). Oʻzbek (lotin) interfeys.

## Vercel orqali ochish (tavsiya)

1. Ushbu papkani GitHub repository ga yuklang.
2. [vercel.com](https://vercel.com) ga kiring → **Add New Project**.
3. GitHub repongizni tanlang.
4. Sozlamalar:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. **Deploy** bosing.

Tayyor URL bir necha daqiqada chiqadi.

## Lokal (ixtiyoriy)

```bash
npm install
npm run dev
```
